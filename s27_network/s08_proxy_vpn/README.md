## 问题 — 你的电脑在公司内网（192.168.x.x），怎么访问 api.anthropic.com？

内网地址（`192.168.x.x`, `10.x.x.x`）是**私有地址**，不能直接在公网上路由。你需要一个中间人帮忙转发。

---

## 核心概念

### NAT — 网络地址转换

```
你(192.168.1.100) → 路由器(NAT) → 公网(1.2.3.4) → api.anthropic.com
                     ↑
               路由器把你的内网地址替换成公网地址
               回包时再换回来
```

NAT 是家庭/公司上网的基础——一个公网 IP 可以让几百台内网设备同时上网。

### HTTP 代理

```
你 → 代理服务器 → api.anthropic.com
      ↑
   代理帮你发请求，收到响应再返回给你
   curl -x http://proxy:8080 https://api.anthropic.com
```

### VPN — 虚拟专用网络

把整个网络流量加密后隧道传输到远程网络，就像你的电脑插在远程局域网里。

---

## 跟 Agent 的关系

- 公司环境 Agent 可能需要配置 `HTTP_PROXY` 环境变量
- MCP 远程传输可能走 VPN 隧道
- 开发者需要知道为什么直连不行、代理怎么配

## 小结

```
NAT    内网→公网的地址翻译(家用路由器)
HTTP代理  帮你转发HTTP请求(公司上网)
VPN    加密隧道，远程接入私网
```
