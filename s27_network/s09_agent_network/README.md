## 问题 — `client.messages.create(...)` 这行代码在网络上经历了什么？

1. DNS 解析 `api.anthropic.com`
2. TCP 三次握手连接 `IP:443`
3. TLS 握手，验证证书，建立加密通道
4. HTTP POST 发送 JSON 请求
5. 等待服务器处理（模型推理）
6. 收到 HTTP 响应

本章把 s01-s08 学的所有东西串起来，完整跟踪一次 API 调用。

---

## 全链路步骤

```
┌── 1. DNS ──────────────────────────────────────┐
│ api.anthropic.com → 1.2.3.4                    │
│ socket.getaddrinfo("api.anthropic.com", 443)   │
└────────────────────────────────────────────────┘
         ↓
┌── 2. TCP ──────────────────────────────────────┐
│ connect(1.2.3.4, 443)                          │
│ SYN → SYN-ACK → ACK (三次握手)                 │
└────────────────────────────────────────────────┘
         ↓
┌── 3. TLS ──────────────────────────────────────┐
│ ClientHello → ServerHello+证书 → 密钥交换      │
│ 证书验证: 域名? CA? 过期?                       │
└────────────────────────────────────────────────┘
         ↓
┌── 4. HTTP ──────────────────────────────────────┐
│ POST /v1/messages HTTP/1.1                      │
│ Authorization: api-key sk-ant-xxx               │
│ Content-Type: application/json                   │
│ {"model":"claude-sonnet-5","messages":[...]}     │
└────────────────────────────────────────────────┘
         ↓
┌── 5. 等待 ──────────────────────────────────────┐
│ 服务器处理 (模型推理，几秒到几十秒)                │
│ keep-alive 保持连接                              │
└────────────────────────────────────────────────┘
         ↓
┌── 6. 响应 ──────────────────────────────────────┐
│ HTTP/1.1 200 OK                                  │
│ {"id":"msg_xxx","content":[...]}                 │
│ stop_reason: "end_turn" 或 "tool_use"            │
└────────────────────────────────────────────────┘
```
