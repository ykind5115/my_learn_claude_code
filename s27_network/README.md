# s27: 网络基础 — 把互联网装进工具箱

[中文](README.md)

> *"互联网不是一个神秘的黑盒。互联网是一个全球快递网络——数据包是包裹，IP 是地址，TCP 是挂号信，HTTP 是信封里的信纸格式。"*
>
> 本课程面向 **网络零基础**的学习者。不假设你懂任何网络协议。
> 每一章只比上一章多一个概念，每一步都用「数据包快递」模型来解释「为什么」。
> 最终目标是：学完能理解 **Agent 的 API 调用从敲下回车到收到响应，网络层到底做了什么**。

---

## 为什么大多数网络教程让人学不会？

大多数教程一上来就甩出 OSI 七层模型——物理层、数据链路层、网络层、传输层……全是抽象概念，没有真实感。

问题在于：**分层是"怎么分类"，不是"为什么"**。不知道数据包像快递一样在网络里一站一站转发，你永远在死记硬背。

**本课程反其道而行之**：先用 s00 帮你建立一个「数据包快递」的心智模型。之后每一章都从这个模型出发，让你知道每个协议在这个快递网络里扮演什么角色。

- Python 基础（会写函数、会用 `import`）
- 一个能敲命令的终端（Git Bash / WSL / Linux / macOS 都行）
- 想理解 Agent 的网络通信是怎么运作的好奇心

> 从 [s00](s00_mental_model/) 开始 — 纯概念，不敲命令，帮你建立心智模型。

## 如何使用本课程

### 学习节奏

1. **读 README 的「问题」部分**
2. **读 README 的「原理」部分** — 用"数据包快递"理解
3. **运行 code.py** — 在终端里看实际效果
4. **自己动手复现**
5. **做练习**

### 不要跳章

每个模块的概念都依赖前一个模块。
