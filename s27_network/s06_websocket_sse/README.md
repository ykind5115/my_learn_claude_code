## 问题 — 服务器怎么主动告诉你"有新消息了"？

HTTP 的对讲机模型：你问一句，服务器答一句。如果想知道有没有新消息，你只能**轮询**——每隔几秒问一次"有新消息吗？"。大部分回答是"没有"，浪费带宽。

**WebSocket**：接通后就是个热线电话，双方随时可以说话。
**SSE (Server-Sent Events)**：服务器单方向推消息，像订阅的新闻推送。

---

## 原理

### WebSocket — 热线电话

```
客户端                                  服务器
  │                                       │
  │── HTTP Upgrade: websocket ──────────→ │ "我要升级成 WebSocket"
  │←── 101 Switching Protocols ──────── │ "好的，切换"
  │                                       │
  │══ 全双工通道 ══════════════════════════│
  │←── 服务器可以随时推送 ────────────── │
  │──→ 客户端也可以随时发 ────────────   │
```

### SSE — 新闻订阅

```
客户端                                  服务器
  │                                       │
  │── GET /events ──────────────────────→ │ "我要订阅"
  │                                       │
  │←── data: {"msg":"hello"}\n\n ───────  │
  │←── data: {"msg":"world"}\n\n ───────  │
  │←── ...持续推送... ─────────────────   │
```
