## 问题 — 你在浏览器里敲了 `api.anthropic.com`，0.3 秒后返回了结果

这 0.3 秒里发生了什么？数据是怎么从 Anthropic 的服务器跨越半个地球到你的电脑的？

---

## 核心模型：数据包快递

```
你的电脑                                       api.anthropic.com
   │                                                │
   │  1. DNS 查地址: "api.anthropic.com 在哪？"      │
   │     → 邮局(DNS)查电话簿 → IP: 1.2.3.4           │
   │                                                │
   │  2. TCP 建立连接: 挂号信握手                    │
   │     → SYN →                                     │
   │     ← SYN-ACK ←                                 │
   │     → ACK →  (三次握手完成)                     │
   │                                                │
   │  3. TLS 加密信道: 加密信封协商                  │
   │     → 交换证书 → 商定密码 → 加密通道建立        │
   │                                                │
   │  4. HTTP 写信                                    │
   │     → POST /v1/messages                        │
   │     → {"model":"claude-sonnet-5",...}          │
   │                                                │
   │  5. 数据包路由: 一站一站转发                     │
   │     你→路由器A→路由器B→...→服务器                │
   │                                                │
   │  6. 响应原路返回                                 │
   │     ← 200 OK + JSON + 模型回答                  │
```

## 角色对照表

| 网络概念 | 快递比喻 | 一句话理解 |
|---------|---------|-----------|
| **数据包** | 快递包裹 | 数据被切成小块，每块独立发出去 |
| **IP 地址** | 收件地址 | `1.2.3.4` = 全网唯一门牌号 |
| **TCP** | 挂号信 | 保证送到、按顺序、不丢失、不重复 |
| **UDP** | 平信 | 快但不保证送到，适合视频直播 |
| **端口** | 公司部门 | IP 找到公司，端口找到部门(80=HTTP前台) |
| **DNS** | 邮局查询台 | 名字→地址，"api.anthropic.com 住哪？" |
| **路由器** | 中转站 | 看地址→转发到下一站→直到目的地 |
| **TLS** | 加密信封 | 别人看到信封但看不到信的内容 |
| **HTTP** | 信纸格式 | "POST /v1/messages" + JSON body |
| **WebSocket** | 热线电话 | 接通后双方随时可以说话 |
