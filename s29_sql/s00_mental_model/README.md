---

## 问题 — Excel 和数据库有什么区别？

Excel 能存数据、能排序、能筛选。为什么还要数据库？

- **并发**：10 个人同时编辑一个 Excel → 冲突。数据库支持多人同时读写
- **数据量**：Excel ~100 万行就卡。数据库轻松处理千万行
- **一致性**：Excel 没有类型检查（"abc"能放进"价格"列）。数据库强制类型约束
- **关联**：两张表怎么连起来？Excel 靠手抄。数据库用 JOIN

## 核心模型：仓库

```
数据库 (Database)
  └── 表 (Table) — 货架
        ├── 列 (Column) — 属性标签: id, name, price, quantity
        ├── 行 (Row)    — 一件件货:
        │     (1, "apple", 3.5, 100)
        │     (2, "banana", 2.0, 200)
        │     (3, "orange", 4.0, 150)
        └── 主键 (PK)   — 每行的唯一编号 (id=1, id=2, ...)

  表之间:
    订单表 (order_id, product_id, qty)
      └── product_id → 产品表的 id (外键 FK)
```

---

## 角色对照

| 概念 | 仓库比喻 | 一句话 |
|------|---------|--------|
| 表 (Table) | 货架 | CREATE TABLE = 定制一个新货架的格式 |
| 列 (Column) | 标签 | 每列有名字和类型 (TEXT, INTEGER, REAL) |
| 行 (Row) | 货物 | INSERT = 放一件货上架 |
| 主键 (PK) | 唯一编号 | 保证每行都能被精确找到 |
| 外键 (FK) | 跨货架标签 | "这件货属于那边的货架 #3" |
| 索引 (Index) | 快速查找目录 | 不用翻遍整个货架 |
| 事务 | 打包操作 | "要么全做，要么全不做" |
