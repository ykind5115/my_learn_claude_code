# s30: 设计模式 — 把代码蓝图装进工具箱

[中文](README.md)

> *"设计模式不是背答案。设计模式是看懂代码的'骨架'——为什么这里用工厂、那里用策略。"*

本课程聚焦 **Agent 系统中真实使用的** 8 个模式。不追求 GoF 23 种全覆盖，追求"看到 Agent 源码能认出模式、理解设计意图"。

---

## 核心比喻："建筑蓝图"

建筑行业有标准设计蓝图——不是让你照抄，是让你理解"为什么门开在这边、窗户设在这个高度"。设计模式也一样：同一个模式在不同语言里写法不同，但**要解决的问题一样**。

---

## 学习路线图

```
s00  心智模型：建筑蓝图             <- 什么是模式、为什么学
s01  单例 Singleton                <- 全局唯一实例
s02  工厂 Factory                   <- 按需创建对象
s03  策略 Strategy                  <- 运行时切换算法
s04  观察者 Observer                <- 事件通知
s05  装饰器 Decorator               <- 不改原函数加功能
s06  适配器 Adapter                 <- 统一不同接口
s07  责任链 Chain of Responsibility <- 请求沿链传递
s08  命令 Command                   <- 操作封装为对象
```
