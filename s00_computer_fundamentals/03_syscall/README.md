# s00-03: 系统调用

[← 返回概览](../README.md) | [上一章：存储](../02_storage/) | [下一章：进程](../04_process/)

> *系统调用是用户态程序访问内核的唯一入口。你的 Python 代码跑在低权限的"用户态"，想读文件、创建进程、收发网络？必须走系统调用。*

---

## 问题 — 为什么普通程序不能直接操作硬件？

如果任何程序都能直接读写磁盘、访问网卡、修改其他进程的内存——一个 bug 就能让整台机器崩溃。

所以操作系统设置了权限分级：

```
┌─────────────────────────┐
│   用户态 (Ring 3)        │  ← 你的 Python 代码在这里
│   不能直接碰硬件         │     所有"正经"程序都在这里
│   不能改内核数据         │
├─────────────────────────┤
│   内核态 (Ring 0)        │  ← OS 内核在这里
│   可以访问所有硬件       │     驱动程序、进程调度、内存管理
│   可以改任何数据         │
└─────────────────────────┘
```

**系统调用就是用户态和内核态之间的唯一通道。**

---

## 核心概念

### 1. 你的 Python 代码底层都在调系统调用

| Python 代码 | 系统调用 | 干什么 |
|------------|---------|--------|
| `open("file.txt")` | `open()` | 打开文件 |
| `os.read(fd, 100)` | `read()` | 读数据 |
| `os.write(fd, data)` | `write()` | 写数据 |
| `subprocess.run()` | `fork()` + `exec()` + `waitpid()` | 创建子进程 |
| `time.sleep(1)` | `nanosleep()` | 让出 CPU |
| `os.getpid()` | `getpid()` | 获取进程 ID |
| `socket.connect()` | `connect()` | 建立网络连接 |
| `os.mkdir("dir")` | `mkdir()` | 创建目录 |

### 2. fork + exec + waitpid — 创建子进程的三步

```
父进程                    内核                    子进程
  │                        │                        │
  │──── fork() ──────────→ │                        │
  │                        │ 复制父进程               │
  │←── 返回子进程PID ────  │                        │
  │                        │←── 返回 0 ──────────── │
  │                        │                        │
  │                        │←── exec("ls") ──────── │
  │                        │ 用 ls 覆盖子进程镜像      │
  │                        │                        │
  │──── waitpid(pid) ────→ │                        │
  │  阻塞等待子进程结束      │←── exit(0) ─────────── │
  │←── 返回退出码 ──────── │                        │
```

### 3. Windows 上是 CreateProcess

Unix 的 `fork+exec` 两步走在 Windows 上不适用。Windows 用 `CreateProcess` 一步到位。但 Python 的 `subprocess` 模块帮你处理了这些差异——你写一样的代码，它在不同平台调不同的系统调用。

## 小结

```
用户态 (你的代码) ──系统调用──→ 内核态 (OS)
                              │
                              ├── 文件操作: open/read/write/close
                              ├── 进程操作: fork/exec/waitpid
                              ├── 网络操作: socket/connect/send/recv
                              └── 其他: sleep/getpid/mmap
```
