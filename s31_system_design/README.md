# s31: 系统设计 — 把架构蓝图装进工具箱

[中文](README.md)

> *"系统设计不是背答案。系统设计是理解权衡——为什么选这个、为什么放弃那个。"*

本课程聚焦于 **Agent 大规模部署时**会遇到的系统设计问题。每个概念用 Python 模拟核心原理。

---

## 核心比喻："城市规划"

单体=一栋大楼，微服务=分散建筑群，负载均衡=分流入口，缓存=前排货架，消息队列=分拣中心，限流=门口栏杆。

---

```
s00  心智模型：城市规划

s05  限流                  <- 防止被打爆
s06  主从复制              <- 数据高可用

```
