## 常见策略

| 策略 | 淘汰规则 | 适用 |
|------|---------|------|
| LRU | 淘汰最久没用的 | 通用 |
| LFU | 淘汰访问次数最少的 | 热点数据 |
| TTL | 过期自动删除 | 有时效性的数据 |
