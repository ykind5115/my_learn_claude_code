> *"高峰期来了 10000 个请求，处理能力只有 1000/s。消息队列帮你削峰填谷。"*

---

## 核心概念

```
生产者 → [Queue] → 消费者
  │                  │
  │ 发消息不用等      │ 按自己的节奏处理
  │ 消费者是否在线    │
```

- **解耦**：生产者和消费者互不知道对方
- **削峰**：请求先进队列，消费者慢慢处理
- **异步**：生产者不等结果就返回
