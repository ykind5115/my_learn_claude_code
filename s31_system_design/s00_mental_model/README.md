## 核心模型：城市规划的 8 个维度

| 城市规划 | 系统设计 | 要解决的问题 |
|---------|---------|-------------|
| 一栋大楼 vs 分散建筑群 | 单体 vs 微服务 | 怎么拆分功能？ |
| 多入口分流 | 负载均衡 | 请求怎么分发到各节点？ |
| 热门商品放前排 | 缓存 | 怎么避免反复查同样的东西？ |
| 邮件分拣中心 | 消息队列 | 高峰期怎么不丢请求？ |
| 门口限流栏杆 | 限流 | 怎么防止系统被冲垮？ |
| 多仓库备份 | 主从复制 | 一个仓库烧了怎么办？ |
| 不可能三角 (快/准/稳) | CAP 定理 | 为什么必须取舍？ |
| 城市总规划图 | Agent 架构 | 大规模 Agent 怎么部署？ |

---

## 系统设计的核心思维：权衡

没有"最优方案"，只有"当前约束下的最优权衡"：
- 要性能 → 加缓存 → 数据可能不一致
- 要可靠 → 多副本 → 成本翻倍
- 要扩展 → 拆微服务 → 运维复杂度爆炸
