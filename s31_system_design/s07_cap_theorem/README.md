> *"为什么一致性、可用性、分区容错不能同时满足？CAP 定理——分布式系统的不可能三角。"*

---

## 三个属性

| 字母 | 含义 | 解释 |
|------|------|------|
| **C**onsistency | 一致性 | 所有节点同一时刻看到相同数据 |
| **A**vailability | 可用性 | 每个请求都能得到响应（可能不是最新） |
| **P**artition Tolerance | 分区容错 | 网络断开时系统仍能工作 |

**CAP 定理**：分布式系统中，C、A、P 最多同时满足两个。

---

## 权衡

```
网络正常 → C + A (不需要 P)
网络断开 → 选 C (一致性, 拒绝请求) 或 A (可用性, 返回可能过时数据)

CP 系统: 银行转账 (宁可不可用也不能出错)
AP 系统: 社交媒体 (先显示出来, 后同步)
```
