---

## 令牌桶

```
每隔 t 秒放一个令牌到桶里 (桶最多 N 个令牌)。
请求来了要拿一个令牌才能通过。
桶空了 → 拒绝请求 (429)。
```

## 滑动窗口

```
统计最近 W 秒内的请求数，超过阈值 → 拒绝。
```
