> *"数据库挂了怎么办？主从复制——主库扛写，从库扛读，主挂了从顶上。"*

---

## 原理

```
Client 写 ──→ [主库] ──复制──→ [从库1]
                              ├→ [从库2]
Client 读 ←── [从库1] 或 [从库2]
```

- **主库**：唯一可写
- **从库**：只读，从主库同步数据
- **故障切换**：主库挂了 → 选一个从库升级为主
